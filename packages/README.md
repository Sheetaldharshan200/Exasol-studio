# Shared Packages

Shared packages should contain contracts and reusable assets that are consumed by more than one runtime boundary.

## Planned Packages

- `shared-types`: typed contracts between UI, Rust core, and services
- `sql-language`: SQL grammar, snippets, completion metadata, and related language assets
- `design-tokens`: theme and token exports
- `e2e-fixtures`: reusable scenarios, data, and helper assets for testing
