# Documentation

This directory holds the project's durable documentation.

## Structure

- [product](./product): product-level vision and full product specification
- [foundation](./foundation/README.md): technical foundation, architecture, tasks, agent model, research notes, ADRs, and diagrams

## Usage

- Update `product` docs when product scope or workflow goals change.
- Update `foundation` docs when architecture, implementation strategy, or contributor guidance changes.
- Record non-trivial architecture decisions as ADRs before implementation spreads them through code.
